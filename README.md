## ⚡ Fast Refresh

This project supports React Fast Refresh through Vite.

Two official React plugins are available:

### Babel

```bash
@vitejs/plugin-react
```

Uses Babel for Fast Refresh.

### SWC

```bash
@vitejs/plugin-react-swc
```

Uses SWC for faster compilation.
